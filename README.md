## Key Concepts

- **Data Ingestion Pipeline**: The process of collecting and preparing data for further processing.
- **Chunks**: Smaller, manageable pieces of unstructured data.
- **Embedding Models**: Models that convert text chunks into numerical vectors.
- **Vector DB**: A database that stores embeddings for efficient similarity search.
- **Similarity Search**: The process of finding vectors in the vector DB that are most similar to the query vector.
